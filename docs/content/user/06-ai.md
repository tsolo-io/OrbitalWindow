# AI chat and models

Sometimes an AI model (a large language model) runs on the server. When it does, the dashboard
shows an **AI model** card with its name. Everything you type stays on this server; nothing is sent
to an outside company.

## Chat

Press **Open chat** on the dashboard. The chat (Open WebUI) opens in a new tab at
`https://{host}:8443/` and signs you in with your OrbitalWindow account. Your conversations are kept
for you and are private to you.

The first time, your browser may warn about the certificate for this address, just as it did for
OrbitalWindow. Accept it the same way.

When nobody is running a model, there is no chat. Ask the person who manages the AI models if you
need one.

## Context window

The dashboard's **AI model** card shows the model's *context window* in tokens: how much text it
can work with at once. That covers your question, the conversation so far (or the files a tool
sends along) and the answer. A token is about three quarters of an English word, so 65,536 tokens
is roughly 50,000 words. When a conversation gets longer than that, start a new chat.

Coding tools such as OpenCode send a lot of text with every request. They need a context of at
least 32,768 tokens. If the dashboard shows less, ask the person who manages the AI models for a
longer context or a smaller model.

## Use the model from your own code

Programs, MATLAB, coding tools such as OpenCode and editors such as Zed and VS Code talk to the
model with the *OpenAI API*. They need three things:

| Setting | Value |
|---|---|
| Address (base URL) | `{api_url}` |
| Model | `{model}` |
| API key | your own key, which starts with `sk-ow-` |

### 1. Get your API key

On the dashboard, open **AI model** → **Use the model from your own code**. It shows your key; press
**Create my key** the first time, then **Copy**. Keep the key private, like a password. **New key**
replaces it; programs with the old key then stop working. The key stays the same when another model
runs; only the model name changes.

Keys from the chat's own settings (they start with `sk-` and work at `https://…:8443/api`) still
work for now, but they will stop in a later version: use the key from the dashboard. The key on the
administrators' **AI** page (it starts with `ow-`) does not work here.

### 2. Trust the server's certificate

If your browser warned about the certificate, programs will refuse it too. Download
[orbitalwindow.crt](/orbitalwindow.crt) and tell the program to trust it, as shown below. This file
is the server's own certificate authority (*OrbitalWindow CA*), so it stays valid when the server
gets a new certificate.

Some programs (for example the Zed editor) use only the certificates installed on your PC. Install
the file there:

- **Windows:** double-click it → **Install Certificate** → **Current User** → **Place all
  certificates in the following store** → **Trusted Root Certification Authorities**, then
  restart the program.
- **Ubuntu:** `sudo cp orbitalwindow.crt /usr/local/share/ca-certificates/` and
  `sudo update-ca-certificates`, then restart the program.

If you installed an older `orbitalwindow.crt` before, remove it first and install the new one.

### 3. Python

```python
import ssl

import httpx
from openai import OpenAI

trust = ssl.create_default_context(cafile="orbitalwindow.crt")  # the downloaded certificate
client = OpenAI(
    base_url="{api_url}",
    api_key="sk-ow-...",  # your key
    http_client=httpx.Client(verify=trust),
)
reply = client.chat.completions.create(
    model="{model}",
    messages=[{"role": "user", "content": "Explain photosynthesis in two sentences."}],
)
print(reply.choices[0].message.content)
```

Install the package once with `pip install openai` (in your own environment, for example
`conda activate science`).

### 4. MATLAB

Install the add-on **Large Language Models (LLMs) with MATLAB** (Home → Add-Ons → Get Add-Ons),
then:

```matlab
chat = openAIChat("You are a helpful assistant.", ...
    ModelName="{model}", ...
    APIKey="sk-ow-...", ...                          % your key
    BaseURL="{api_url}");
reply = generate(chat, "Explain photosynthesis in two sentences.")
```

If MATLAB refuses the connection because of the certificate, install `orbitalwindow.crt` on your
PC as shown in step 2, then restart MATLAB.

### 5. Coding tools (OpenCode)

Put this in `opencode.json` in your project folder (or in `~/.config/opencode/opencode.json` for
every project):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "orbitalwindow": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "OrbitalWindow",
      "options": {
        "baseURL": "{api_url}",
        "apiKey": "sk-ow-..."
      },
      "models": {
        "{model}": {
          "name": "{model}",
          "limit": { "context": {context}, "output": 8192 }
        }
      }
    }
  }
}
```

Then start OpenCode so it trusts the certificate, and choose the model with `/models`:

```bash
NODE_EXTRA_CA_CERTS=/path/to/orbitalwindow.crt opencode
```

The model and context above are those of the model running now. When another model runs, change
them to what the dashboard shows.

## Code completion in your editor

Your editor can suggest code while you type: a grey suggestion appears at the cursor, and **Tab**
accepts it. This works in **Zed** and in **VS Code** (with the Continue extension).

### Before you start

1. **Check the model.** On the dashboard, open **AI model** → **Use the model from your own code**
   and read **Code completion**. It tells you if the running model can complete code. A *coder*
   model (for example `Qwen/Qwen2.5-Coder-3B`) gives the best suggestions.
2. **Get your API key** on the same place (**Create my key**, then **Copy**). It starts with
   `sk-ow-`.
3. **Install the certificate** `orbitalwindow.crt` on your PC (see *Trust the server's
   certificate* above), then restart the editor. Editors only trust certificates that are
   installed on the PC.

You need these values. The model is the one running now:

| Setting | Value |
|---|---|
| Code completion address | `{api_url}/completions` |
| Chat address | `{api_url}` |
| Model | `{model}` |
| API key | your key (`sk-ow-…`) |

### Zed

1. **Give Zed your key.** Zed reads it from the environment variable
   `ZED_OPEN_AI_COMPATIBLE_EDIT_PREDICTION_API_KEY`:
   - Windows: open *Edit the system environment variables* → **Environment Variables…** → under
     *User variables* press **New…**, name `ZED_OPEN_AI_COMPATIBLE_EDIT_PREDICTION_API_KEY`, value
     your key.
   - Ubuntu: add `export ZED_OPEN_AI_COMPATIBLE_EDIT_PREDICTION_API_KEY=sk-ow-...` to `~/.profile`,
     then log out and in again.
2. **Open Zed's settings file:** press `Ctrl+Shift+P`, type `open settings file`, press **Enter**.
3. **Add this** inside the outer `{ }` (keep what is already there; mind the commas):

    ```
    "edit_predictions": {
      "provider": "open_ai_compatible_api",
      "open_ai_compatible_api": {
        "api_url": "{api_url}/completions",
        "model": "{model}",
        "prompt_format": "infer",
        "max_output_tokens": 256
      }
    },
    "language_models": {
      "openai_compatible": {
        "OrbitalWindow": {
          "api_url": "{api_url}",
          "available_models": [
            { "name": "{model}", "max_tokens": {context}, "max_output_tokens": 8192 }
          ]
        }
      }
    }
    ```

   The first part is code completion, the second is the chat in Zed's agent panel (Zed asks for
   the key there the first time). `"prompt_format": "infer"` lets Zed pick the right format from
   the model name; for a Qwen model you can also write `"qwen"`.
4. **Restart Zed** and type some code in a file. After a moment a grey suggestion appears.

### VS Code (Continue)

1. In VS Code, open **Extensions** (`Ctrl+Shift+X`), search for **Continue** and press
   **Install**.
2. Open Continue's settings file: click the Continue icon on the left, then the gear, then
   **Open configuration file**. It is `config.yaml` in the `.continue` folder of your home folder.
3. Add the model under `models:` (replace `sk-ow-...` with your key and the path with where you
   saved `orbitalwindow.crt`):

    ```yaml
    models:
      - name: OrbitalWindow
        provider: openai
        model: {model}
        apiBase: {api_url}
        apiKey: sk-ow-...
        roles: [chat, autocomplete]
        requestOptions:
          caBundlePath: C:/Users/you/Downloads/orbitalwindow.crt
    ```

4. Save the file and type some code. Continue shows grey suggestions; **Tab** accepts them.

The *llama.vscode* extension does not work with OrbitalWindow; use Continue.

### If nothing appears

- **The dashboard says the model can't complete code**: ask the person who manages the AI for a
  coder model. Chat still works.
- **A certificate error** (`UnknownIssuer`, `certificate verify failed`): install
  `orbitalwindow.crt` on the PC and restart the editor.
- **401 or "invalid key"**: the key is wrong, or you pressed **New key** on the dashboard. Copy the
  key again.
- **Another model now runs**: change the model name in the editor's settings to the one on the
  dashboard.
- Tools that send the code after the cursor as a separate `suffix` field do not work with every
  model engine. Zed and Continue work.

## Benchmarks

**Benchmarks** at the top of the page lists how well each model did on coding tests (HumanEval+ and
MBPP+). The *plus* score is the share of programming tasks the model solved correctly; higher is
better. **Report** shows every task and the code the model wrote.

## Good to know

- The model is shared by everyone. When many people use it at once, answers take a little longer.
- The model can be wrong. Check facts, numbers and references before you rely on them.
- If the model is stopped, programs get an error until it runs again.
