# AI chat and models

Sometimes an AI model (a large language model) runs on the server. When it does, the dashboard
shows an **AI model** card with its name. Everything you type stays on this server; nothing is sent
to an outside company.

## Chat

Press **Open chat** on the dashboard. The chat (Open WebUI) opens in a new tab at
`https://{host}:8443/` and signs you in with your OrbitalWindow account. Your conversations are kept
for you and are private to you.

The first time, your browser may warn about the certificate for this address, just as it did for
OrbitalWindow. Accept it the same way.

When nobody is running a model, there is no chat. Ask the person who manages the AI models if you
need one.

## Context window

The dashboard's **AI model** card shows the model's *context window* in tokens: how much text it
can work with at once. That covers your question, the conversation so far (or the files a tool
sends along) and the answer. A token is about three quarters of an English word, so 65,536 tokens
is roughly 50,000 words. When a conversation gets longer than that, start a new chat.

Coding tools such as OpenCode send a lot of text with every request. They need a context of at
least 32,768 tokens. If the dashboard shows less, ask the person who manages the AI models for a
longer context or a smaller model.

## Use the model from your own code

Programs, MATLAB and coding tools such as OpenCode talk to the model with the *OpenAI API*. They
need three things:

| Setting | Value |
|---|---|
| Address (base URL) | `{chat_api}` |
| Model | `{model}` |
| API key | your own key, which starts with `sk-` |

### 1. Get your API key

On the dashboard, open **AI model** → **Use the model from your own code**. It shows your key; press
**Create my key** the first time, then **Copy**. Keep the key private, like a password. **New key**
replaces it; programs with the old key then stop working.

You can also find it in the chat: click the round picture at the bottom left → **Settings** →
**Account** → **API keys**: press **Show** next to *Secrets* and use **API Key**. Do not copy the
*JWT Token* above it: that one stops working after a while.

The key on the administrators' **AI** page (it starts with `ow-`) does not work here.

### 2. Trust the server's certificate

If your browser warned about the certificate, programs will refuse it too. Download
[orbitalwindow.crt](/orbitalwindow.crt) and tell the program to trust it, as shown below.

### 3. Python

```python
import ssl

import httpx
from openai import OpenAI

trust = ssl.create_default_context(cafile="orbitalwindow.crt")  # the downloaded certificate
client = OpenAI(
    base_url="{chat_api}",
    api_key="sk-...",  # your key
    http_client=httpx.Client(verify=trust),
)
reply = client.chat.completions.create(
    model="{model}",
    messages=[{"role": "user", "content": "Explain photosynthesis in two sentences."}],
)
print(reply.choices[0].message.content)
```

Install the package once with `pip install openai` (in your own environment, for example
`conda activate science`).

### 4. MATLAB

Install the add-on **Large Language Models (LLMs) with MATLAB** (Home → Add-Ons → Get Add-Ons),
then:

```matlab
chat = openAIChat("You are a helpful assistant.", ...
    ModelName="{model}", ...
    APIKey="sk-...", ...                             % your key
    BaseURL="{chat_api}");
reply = generate(chat, "Explain photosynthesis in two sentences.")
```

If MATLAB refuses the connection because of the certificate, install `orbitalwindow.crt` on your
PC: double-click it → **Install Certificate** → **Current User** → **Place all certificates in the
following store** → **Trusted Root Certification Authorities**, then restart MATLAB.

### 5. Coding tools (OpenCode)

Put this in `opencode.json` in your project folder (or in `~/.config/opencode/opencode.json` for
every project):

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "orbitalwindow": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "OrbitalWindow",
      "options": {
        "baseURL": "{chat_api}",
        "apiKey": "sk-..."
      },
      "models": {
        "{model}": {
          "name": "{model}",
          "limit": { "context": {context}, "output": 8192 }
        }
      }
    }
  }
}
```

Then start OpenCode so it trusts the certificate, and choose the model with `/models`:

```bash
NODE_EXTRA_CA_CERTS=/path/to/orbitalwindow.crt opencode
```

The model and context above are those of the model running now. When another model runs, change
them to what the dashboard shows.

## Benchmarks

**Benchmarks** at the top of the page lists how well each model did on coding tests (HumanEval+ and
MBPP+). The *plus* score is the share of programming tasks the model solved correctly; higher is
better. **Report** shows every task and the code the model wrote.

## Good to know

- The model is shared by everyone. When many people use it at once, answers take a little longer.
- The model can be wrong. Check facts, numbers and references before you rely on them.
- If the model is stopped, programs get an error until it runs again.
